# 📻 محطة كنعان للحروف

**أستمع → أميّز → أكتشف → أنطق → أبني → أكتب → أوظّف**

🌐 **الموقع:** https://maha90-ops.github.io/kanaan-station/
(منشور تلقائيًا عبر GitHub Pages من الفرع `main`؛ الميكروفون يعمل لأن الرابط https.)

بيئة تعلم رقمية لتعليم الحروف العربية للمرحلة الأساسية المبكرة: **محطة إذاعية + مختبر أصوات + ورشة كتابة + لعبة تعلم**.
الفكرة: الطفل لا يرى الحرف أولًا، بل يسمعه، يميّزه، يكتشف رمزه، ينطقه، يبني به كلمة، يكتبه، ثم يوظّفه.

## التشغيل

```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000
```

لا بناء ولا حزم. الميكروفون يعمل على `localhost` أو `https`. لفتح حرف محدد: `?ep=baa`.

## رحلة كل حرف (٧ مراحل، قالب واحد لكل الحروف)

| # | المرحلة | ماذا يحدث | لماذا |
|---|---|---|---|
| ١ | 🎙️ أستمع | كنعان: «استمع جيدًا… هناك صوت يختبئ في محطة الحروف»، ثم يبثّ الراديو «بَ بَ بَ» | الأذن قبل العين: لا حرف ولا صورة |
| ٢ | 👂 أميّز | ثلاث بطاقات **أصوات** (صوت ١ · ٢ · ٣) تُسمع عند لمسها، ثم «هذا هو الصوت!» | تمييز سمعي خالص؛ بعد النجاح تنكشف حروف الأصوات. محاولتان خاطئتان ← دعامة مقارنة بالصوت الأقرب |
| ٣ | 🔎 أكتشف | يخرج الحرف تدريجيًا من الراديو: «أحسنت! لقد اكتشفت الحرف.» + تلميح بصري (النقاط) | الصوت أولًا ثم الرمز |
| ٤ | 🗣️ أنطق | «الآن دورك!» + 🎙️ سجّل نطقك ← تغذية راجعة تكوينية + استمع لصوتك/للنموذج | التقييم تقريبي **ولا يمنع التقدّم أبدًا** |
| ٥ | 🧩 أبني | «لنَبْنِ كلمة!» بطاقات تُسحب أو تُلمس ← تظهر الكلمة متصلة ثم **صورتها**: «رائع! لقد بنيت كلمة بَيْت.» | الصورة مكافأة معنى بعد البناء، لا تلميح |
| ٦ | ✍️ أكتب | ورشة كتابة بثلاثة مستويات (انظر أدناه) | من التتبّع إلى الكتابة المستقلة |
| ٧ | 🎯 أوظّف | «أين تسمع صوت ب في كلمة بَيْت؟» (بداية/وسط/نهاية، مع 🐢 إبطاء) ثم **ثلاث قنوات** بكلمات جديدة تُسمع قبل أن تُرى | انتقال من التعرّف إلى الاستخدام |

ثم: رسالة النجاح (المراحل السبع بلغة «استمعت، ميّزت…») ← 🔴 على الهواء (يُبثّ صوت الطفل) ← ✉️ الرسالة الغامضة + مهمة خارج الشاشة.
وفي بداية الحلقة التالية (إن وُجدت حروف سابقة): 🔎 تقرير المهمة و🗄️ رسالة من الأرشيف (مراجعة متباعدة).

**شريط الرحلة** في أعلى كل شاشة: المكتملة ✓ + الفعل الماضي (استمعت)، الحالية رقم مملوء وخط عريض، القادمة رقم في دائرة فارغة — المعنى في الشكل والنص لا في اللون وحده.

## ✍️ ورشة الكتابة

| المستوى | الدعم |
|---|---|
| ١ أتتبّع | مسار منقّط كثيف + **نقطة بداية خضراء** + **سهم الاتجاه** + «👀 شاهد كيف يُكتب» (عرض متحرك للمسار) |
| ٢ أُكمل | نقاط أقل ومسار أخف، مع نقطة البداية |
| ٣ أكتب | دون مسار؛ يكتب الطفل الحرف بنفسه في أي موضع وحجم |

- **لمس + قلم + فأرة** (Pointer Events)، والصفحة لا تتحرك أثناء الكتابة.
- **التقييم تقديري ولطيف:** نقارن الحبر بشكل الحرف (التغطية والدقة)، وفي المستوى الثالث بعد مواءمة الحجم والموضع ونسبة العرض للارتفاع. تلميحات محددة: «ابدأ من النقطة الخضراء»، «لا تنسَ النقطة». عند «محاولة جميلة» يظهر الشكل الصحيح خفيفًا للمقارنة. الانتقال للمستوى التالي متاح دائمًا.
- **تركيز:** أثناء الكتابة لا يظهر المرشد؛ التعليمات نص فوق اللوحة وبصوت كنعان.
- **مسارات الحرف** في بياناته (`writing.strokes` بإحداثيات لوحة 240×240، أول نقطة = البداية، و`dots` للنقاط). حرف بلا مسارات يُتتبَّع **شكل الخط نفسه** (Noto Naskh) — فكل الحروف الـ٢٨ تعمل فورًا، والمسارات تحسين لاحق.

## الصفحة الرئيسية: الاستوديو الحيّ

مركز الانتباه: **كنعان + الراديو + الصوت + زر ابدأ الاستماع** (أكبر زر وأوضحه). الساعة أصغر وثانوية، وأزرار المكتب الأربعة هادئة.

- **كنعان:** رمش طبيعي، وحين يتكلم فقط: شفتان مع الصوت، إيماءة رأس، حركة يد، وتعبيرات قصيرة (هزّة فرِحة عند النجاح، ميل مشجّع عند إعادة المحاولة). حين يصمت: ساكن.
- **الراديو مركز الصوت:** موجات بث فوق الهوائي وموجة صوتية على الشاشة — **ساكنتان دون صوت**، تتحركان مع أي صوت ثم تهدآن. كل راديو في كل شاشة يتصرف بالقاعدة نفسها.
- **الساعة:** عقارب بالوقت الحقيقي (دون عقرب ثوانٍ)، وتحتها «● على الهواء الآن»، والضغط يُظهر «أنت الآن على الهواء مع كنعان».
- **ابدأ الاستماع:** كنعان يقول «هيا نستمع!» في الاستوديو (شفاه + موجات) ثم يبدأ المسار. لا يظهر الحرف.
- **قاعدة الحركة:** لا تتحرك العناصر معًا أبدًا؛ زر «أوقف الحركة» + احترام «تقليل الحركة» في النظام.

## الحروف والمنهج

| المجموعة | الحروف (الكلمة) |
|---|---|
| الأولى | ا (أَرْنَب) · ب (بَيْت) · ت (تِين) · ث (ثَوْب) · ج (جَمَل) · ح (حِصَان) · خ (خُبْز) · د (دِيك) · ذ (ذُرَة) |
| الثانية | ش (شَمْس) · م (مَوْز) · ز (زَيْت) · ع (عِنَب) |

الكلمات مختارة لسهولتها ووضوح صوتها الأول وإمكانية رسمها؛ والهوية الفلسطينية في البيئة والمشاهد (البيت الحجري، الثوب المطرّز، خبز الطابون، القرية).
**الترتيب في `js/data/curriculum.js` فقط** — غيّره دون لمس أي حرف. لكل مجموعة «رسالة غامضة» تعود إليها حروفها.

### إضافة حرف (من الـ٢٨)

ملف بيانات واحد في `js/data/letters/<id>.js` + سطر في `index.html` + معرّفه في مجموعة في `curriculum.js`:

```js
Kanaan.Letters.add({
  id: 'qaaf', letter: 'ق',
  word: { text: 'قَمَر', letters: ['ق', 'م', 'ر'], scene: 'moon', alt: 'قمر فوق البيوت' },
  options: ['ك', 'ق', 'ج'],                                   // تمييز سمعي (أصوات)
  transfer: [['كَعْك', false], ['قِطَّة', true], ['دَار', false]],
  writing: { strokes: ['M…'], dots: [[x, y], [x, y]] },       // اختياري
  revealHint: 'انظر: فوق الحرف ق نقطتان.'
});
```

كل ما عدا ذلك يُولَّد: اسم الحرف وصوته وأصوات الخيارات وصوت المقارنة وطريقة تقييم النطق (من `alphabet.js` للحروف الـ٢٨)، البطاقات المبعثرة، موضع الصوت في الكلمة، الحرف الأول لكلمات النقل، وكل عبارات كنعان والتغذية الراجعة (`registry.js`). المشهد: رسمة في `scenes.js` أو `word.image` لصورة.

## 🔊 الصوت: كل صوت له اسم، والملف اختياري

لا صوت مكتوب داخل الكود. كل ما يُنطق له **اسم ثابت** (cue)؛ إن وُجد ملف بهذا الاسم يُشغَّل، وإلا الصوت الآلي العربي:

| الاسم | ماذا |
|---|---|
| `phonemes/ب` | صوت الحرف «بَ» (للهدف وخيارات التمييز وصوت المقارنة) |
| `listen/ب` | نموذج الاستماع «بَ بَ بَ» |
| `words/بيت` | نطق كلمة (دون تشكيل) |
| `common/feedback.discrimination.correct` | جملة لكنعان واحدة لكل الحروف |
| `letters/baa/script.reveal` | جملة لكنعان خاصة بحرف |

1. `node tools/recording_list.js` ← يكتب `assets/audio/RECORDING_LIST.md`: **كل اسم ونصه** (271 تسجيلًا حاليًا).
2. ضع الملفات في `assets/audio/` بأسمائها (`.mp3` أو `.m4a` أو `.ogg` أو `.wav`) — تدريجيًا، أي جزء يكفي.
3. `python3 tools/build_audio_manifest.py` ← يحدّث القائمة. انتهى.

مع الملفات المسجّلة يصير **تزامن شفاه كنعان وموجة الراديو حقيقيًا** (يُقرأ الصوت لحظة بلحظة)؛ مع الصوت الآلي يُقدَّر إيقاع المقاطع.

## الوصول و UDL

عربية كاملة RTL، خط واضح وكبير، أزرار كبيرة، تباين مرتفع، لوحة مفاتيح، لمس وفأرة وقلم، إعادة المحاولة في كل نشاط، تشغيل/إيقاف صوت كنعان، «أوقف الحركة»، احترام «تقليل الحركة»، ولا معلومة تعتمد على اللون وحده.

## آلية التسجيل الصوتي وتقييم النطق

```
[🎙️ اضغط وسجّل]
   │ getUserMedia({ echoCancellation:false, noiseSuppression:false, autoGainControl:false })
   │   (كبت الضوضاء يحذف الأصوات الاحتكاكية مثل ش، لذلك نوقفه)
   ├──► MediaRecorder ──► ملف في الذاكرة ──► «▶ استمع لصوتك» (مقارنة ذاتية بالنموذج)
   └──► AnalyserNode (FFT 2048) كل ~٢٠ م.ث:
          rms                 شدة الصوت (لمؤشر المستوى ولفصل الصمت)
          low   80–1000 هـ    طاقة مجهورة (نغمة الحنجرة / حروف العلة)
          target 1700–5200 هـ نطاق الشين
          competitor 5200–11000 هـ نطاق السين (الخلط الأشيع)
   ⏹ إيقاف يدوي أو تلقائي بعد ٤ ثوانٍ
```

**التقييم (`pronunciation.js`):**

1. إطارات نشطة = الشدة فوق عتبة متكيّفة مع ضجيج الغرفة.
2. إطار احتكاكي = طاقة النطاقات العليا > ضعف الطاقة المجهورة.
3. إطار «شيني» = طاقة نطاق الشين ≥ ٠٫٩ × طاقة نطاق السين.
4. الثقة = ٠٫٤٥ × (مدة الاحتكاك) + ٠٫٥٥ × (نسبة الإطارات الشينية).

**المقيّمات حسب فئة الصوت:**

- **`fricative` (ش):** يقيس مدة الهواء ونطاق طاقته، فيميّز ش من س.
- **`voicedFricative` (ز):** يبحث عن هواء عالي التردد مع اهتزاز الحنجرة. إذا وُجد هواء بلا اهتزاز يقول «يشبه س»، مع تلميح: «ضع يدك على رقبتك».
- **`nasal` (م):** يبحث عن طنين بشفتين مغلقتين، أي طاقة شبه معدومة فوق ١ ك.هـ. إذا سمع صوتًا مفتوحًا يقول «أغلق شفتيك».
- **`clarity` (ب، ت، ع):** لا يدّعي أي حكم على صحة المخرج، بل يتحقق فقط من أن الصوت وصل بوضوح. يرى الطفل: «سمعتُ صوتك بوضوح! استمع لصوتك وقارنه بالنموذج»، وتتغيّر الملاحظة أسفل الشاشة لتقول ذلك صراحة.

**مثال: معايير المقيّم `fricative` (ش):**

| النتيجة | الشرط | ما يراه الطفل |
|---|---|---|
| 🌟 ممتاز | احتكاك ≥ ٢٥٠ م.ث و٦٠٪+ شيني | «رائع! نطقك واضح.» |
| 👍 قريب | احتكاك موجود لكنه قصير أو يشبه «س» | «محاولة جميلة!…» + تلميح نطقي محدد |
| 🔁 إعادة | صمت، أو صوت بنغمة دون هواء | «لنحاول معًا…» + تلميح («ضع إصبعك على فمك كأنك تقول اسكت») |

**تم التحقق آليًا** بميكروفون وهمي وأصوات اصطناعية:

| الحلقة | الصوت المُدخَل | النتيجة |
|---|---|---|
| ش | ضوضاء ٢–٤٫٨ ك.هـ (يشبه ش) | ممتاز |
| ش | ضوضاء ٥٫٨–١٠ ك.هـ (يشبه س) | قريب + «يشبه س» |
| ز | طنين + ضوضاء عالية (يشبه ز) | ممتاز |
| ز | ضوضاء بلا طنين (يشبه س) | قريب + «ضع يدك على رقبتك» |
| ز | حرف علة / طنين فقط | إعادة + «قرّب أسنانك» |
| م | طنين منخفض (يشبه م) | ممتاز |
| م | حرف علة مفتوح | قريب + «أغلق شفتيك» |
| ب | أي صوت واضح | «سمعتُ صوتك بوضوح» |

هذه أصوات اصطناعية، والحدود الرقمية ما زالت تحتاج إلى ضبط بتسجيلات أطفال حقيقيين.

**ما لا يدّعيه النظام:** هذا تحليل لشكل الصوت وليس تعرّفًا على الكلام. لا يميّز «ش» عن «ث» أو «ف» بدقة، ويتأثر بجودة الميكروفون وضجيج الصف. لذلك:

- زر «متابعة» متاح بعد أول محاولة مهما كانت النتيجة.
- إعادة المحاولة واستماع الطفل إلى صوته متاحان دائمًا.
- إن لم يتوفر الميكروفون أو رُفض الإذن، يظهر مسار «نطقتُ الصوت» (تقرير ذاتي/بحضور المعلم) ويُسجَّل كذلك.
- كل المعالجة محلية، ولا يُرسَل أي صوت إلى أي خادم.

## السجل التكويني

يُحفظ في `localStorage` تحت المفتاح `kanaan-station:v1`:

```js
episodes.baa.activities = {
  discrimination: { attempts, success, firstTry },
  revealed:       { success },
  pronunciation:  { attempts, completed, mode: 'mic'|'self-report', levels: [...], best, lastMetrics },
  wordBuilding:   { attempts, success, firstTry },
  meaning:        { attempts, success, firstTry },
  transfer:       { attempts, success, firstTry, channelsHeard },
  listened:       { success, times },
  writing:        { completed, levels: { trace, complete, free } }
}
```

يراه الطفل فقط كشريط الرحلة (٧ مراحل: ✓ استمعت … ○ أوظّف). ويراه المعلم في «ملخّص للمعلّم» على شاشة النجاح، أو عبر `Kanaan.debug.export()` في وحدة التحكم.
